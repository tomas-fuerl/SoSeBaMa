# Qualitätsanforderungen

## Bezug und Messregel

Dieses Dokument konkretisiert GitHub-Issue #3. Jede Anforderung besitzt eine
stabile `QR-xxx`-Kennung. Ein fehlender Zahlenwert wird nicht durch Codex
erfunden, sondern auf eine offene `OQ-xxx`-Entscheidung verwiesen.

Vor einer Produktfreigabe werden die Anforderungen in DEV geprüft, in TST unter
repräsentativen Bedingungen verifiziert und in PRD ohne Debugzugang
beobachtbar gemacht.

## Nachweisführung

Prüfnachweise enthalten Anforderungs-ID, Umgebung, Ausgangszustand, aktiven
Bandbereich, Ergebnis und bekannte Abweichung.

Eine nicht messbar abgeschlossene offene Frage blockiert die Freigabe der davon
abhängigen Anforderung oder benötigt eine dokumentierte Eigentümerentscheidung
nach [Projekt-Governance](../GOVERNANCE.md).
