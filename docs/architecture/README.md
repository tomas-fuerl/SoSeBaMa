# Architektur

## Zweck

Diese Ablage dokumentiert die angenommene technische und betriebliche
Architektur von SoSeBaMa. Produktverhalten bleibt in den
[Produktdokumenten](../product/VISION.md) verbindlich. Das fachliche Verhältnis
von Songs, Inhalten und Overlays steht im
[Inhalts- und Overlaymodell](CONTENT-AND-OVERLAY-MODEL.md).

## Status

Die Architekturgrundlage wurde am 2026-07-30 angenommen. Sie ist noch nicht
implementiert. Das Repository enthält keine funktionsfähige Anwendung.

Einzelentscheidungen folgen dem [ADR-Verfahren](../ADR.md). Der
[ADR-Index](decisions/README.md) enthält `ADR-0001` bis `ADR-0016`.
